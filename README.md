# LabFlow · 实验室设备预约平台

福州大学实验室设备预约平台的课程项目实现：学生预约实验设备、教师审批与维护、管理员管理账号，全流程在浏览器中完成。

| 项 | 内容 |
| --- | --- |
| 课程 | EE308FZ 软件工程 |
| 作业 | 第五次作业 · Alpha Sprint（2026-11-21 ~ 2026-11-28） |
| 小组 | LabRunners（14 人） |
| 冲刺目标 | 一键部署可复现、扫码闭环打通、通知与统计对齐 SRS、回归测试全绿 |

## 技术栈

- 运行时：Node.js 24（使用内置 `node:sqlite` 与 `node:http`），**零第三方运行时依赖**
- 前端：原生 HTML/CSS/JS，与学生端、教师端同源部署
- 数据：SQLite 文件库，报修照片存本地目录
- 测试：`node --test` 端到端接口测试

## 快速启动

```powershell
node src/server.js
```

浏览器打开 <http://127.0.0.1:3000/>。Windows 也可直接双击 `start.bat`。

演示账号：

| 身份 | 用户名 | 密码 |
| --- | --- | --- |
| 学生 | `student` | `Student@2026` |
| 教师 / 实验室管理员 | `teacher` | `Teacher@2026` |
| 系统管理员 | `admin` | `Admin@2026` |

首次启动会自动建库并写入演示设备。重置数据时停止服务、删除 `data/labflow.db` 与 `data/uploads/` 内的照片，再次启动即可。

## 关键业务规则

- 设备有效状态由“配置状态 + 当前正在进行的已批准预约”共同计算：`maintenance` / `reserved` / `available`
- 预约须晚于当前时间、按 30 分钟对齐、单次 0.5–4 小时、在 08:00–22:00 内
- 新预约与同设备同日的待审核、已批准记录做重叠校验，批准时再次校验
- 已批准预约须在开始前 30 分钟取消；待审核可取消至开始时间
- 开始维修将设备置为维修中，最后一条处理中报修完成后恢复空闲
- 设备存在待审核/已批准预约或待处理/处理中报修时禁止删除

## 说明

本项目用于课程演示与本地验收：数据库使用 SQLite 而非 PostgreSQL，使用本地账号而非校园统一身份认证，预约前 15 分钟提醒以站内通知实现。生产部署所需的迁移点在 `docs/ARCHITECTURE.md` 中列出。
