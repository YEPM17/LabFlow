# LF-A2 异常态与降级设计

周琰昭（832401227）｜Issue #4｜2026-11-22
## 五种异常态

| 场景 | 触发时机 | 提示 | 降级路径 |
| --- | --- | --- | --- |
| 校验失败 | 客户端解析后，未发请求 | “这不是 LabFlow 的设备标签” | 手输编号 |
| 设备已删除 | 查询返回不存在 | “该设备已不在设备目录中” | 返回设备目录 |
| 设备维修中 | 状态为 maintenance | “该设备正在维修，暂不可预约” | 换设备 |
| 相机不可用 | 权限拒绝或无摄像头 | “无法使用相机，请手动输入编号” | 手输编号 |
| 网络失败 | 解析成功但请求失败 | 顶部提示条 + 重试按钮 | 保留载荷重试 |

## 设计原则

- 客户端能判的错不发给服务器：校验位不过就不发请求，省一次往返也避免日志噪声
- 每种异常都给出下一步动作，不留“仅报错”的死路
- 文案不出现错误码，错误码只在日志里
