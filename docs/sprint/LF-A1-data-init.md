# LF-A1 数据初始化说明

彭孟欢（832401214）｜Issue #11｜2026-11-22
## 启动时做什么

1. 读 `DB_PATH`（默认 `data/labflow.db`），不存在则建库
2. 执行 `src/schema.sql`，建表与索引
3. 首次为空时写入 5 台演示设备与三个演示账号（scrypt 哈希，无明文）
4. 启动 30 秒轮询的提醒调度器

## 重置流程

停止服务 → 删除 `data/labflow.db` 与 `data/uploads/` 内照片 → 重新启动。用于演示前清场，不用于生产。

## 演示数据

`scripts/seed-demo.js` 可单独执行，写入“今日历史已批准、明日已批准、待审核、待处理报修”，让统计与通知页面在演示时不为空。

## 报修链路回归（LF-A7 部分，11/26）

提交（含 3 张照片上限）→ 教师开始维修（设备转 maintenance）→ 完成维修（无其它处理中报修时恢复 available）→ 学生收到两条通知。
