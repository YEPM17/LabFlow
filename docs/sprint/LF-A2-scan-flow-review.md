## 评审范围

## 四项冻结决策

| 决策 | 结论 | 理由 |
| --- | --- | --- |
| 载荷格式 | `labflow://d/<deviceId>?c=<checksum>` | 设备 ID 已是全站主键；校验位挡住伪码与串场标签 |
| 跳转路径 | 扫码 → 解析 → 查设备 → 预填面板 | 不新建页面，复用现有预约面板 |
| 权限边界 | 只调 `GET /devices/:id` 与 `availability` | 这两个接口本来就不返回学生身份，扫码不额外泄露信息 |
| 失败处理 | 可恢复提示 + 手输降级 | 实验室光线差、标签磨损是常态 |
