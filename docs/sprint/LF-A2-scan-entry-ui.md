# LF-A2 扫码入口 UI 说明

王梓涵（832401220）｜Issue #3｜2026-11-22
## 入口

学生工作台设备目录右上角，与 `# 按编号查询` 同一位，点击后展开扫码区，不新开页面。

## 交互顺序

1. 点击入口 → 相机预览（未授权时先弹权限说明）
2. 识别成功 → 底部浮层显示设备名、实验室、当前状态
3. 点击“预约此设备” → 打开预约面板，设备已选、时间待选

## 面板字段

| 字段 | 来源 | 是否可改 |
| --- | --- | --- |
| 设备名 | `GET /devices/:id` | 否 |
| 实验室 | 同上 | 否 |
| 当前状态 | 同上（available / reserved / maintenance） | 否 |
| 日期、起止时间 | 学生选择 | 是 |

## 空态与提示

- 识别中：浮层显示设备号码占位，不显示加载圈外的骨架屏，避免误以为已出结果
- 维修中：状态标签用红色，预约按钮置灰并说明原因
- 未登录：保留已解析载荷，登录后自动续上流程

## 一致性

按钮圆角、状态色沿用 `public/style.css` 现有变量，不新增色板。
