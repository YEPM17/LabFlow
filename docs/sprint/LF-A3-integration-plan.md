谢宇城（832401224）｜Issue #10｜2026-11-24
## 联调顺序

1. 登录 → 学生目录 → 预约创建（happy path）
2. 冲突：同设备同时段二次提交
3. 审核：教师通过 / 拒绝（含原因）
4. 取消：待审核随时取消、已批准 30 分钟前取消
5. 报修：提交 → 开始维修 → 完成（设备状态联动）

## 错误码对照

| 场景 | 后端 | 前端提示要求 |
| --- | --- | --- |
| 时段冲突 | `RESERVATION_CONFLICT` | 指出冲突区间，可改选 |
| 重复审核 | `ALREADY_REVIEWED` | 提示已处理，刷新列表 |
| 取消超时 | `CANCEL_WINDOW_CLOSED` | 显示截止规则（开始前 30 分钟） |
| 设备维修中 | `DEVICE_IN_USE` / 状态校验 | 说明维修中不可预约 |

每条链路至少一次端到端手工复核，截图归档；接口层已有 `node --test` 覆盖，联调只补前端提示与状态刷新。
