# LF-A6 响应式与无障碍要点

刘冉（832401215）｜Issue #12｜2026-11-25
## 断点

| 断点 | 布局 |
| --- | --- |
| ≥1440 | 目录三列，统计四列 |
| 1024–1439 | 目录三列，统计两列 |
| 768–1023 | 目录两列，统计两列 |
| <768 | 全部单列，浮层全宽 |

## 无障碍基线

- 表单控件都有可见 label，占位符不作为唯一说明
- 焦点态保持 2px 可见描边，不用 `outline: none` 硬抹
- 正文与背景对比度 ≥ 4.5:1；状态标签不只用颜色区分，额外加文字
- 浮层打开时焦点进入浮层，关闭后回到触发按钮
- 动效尊重 `prefers-reduced-motion`
